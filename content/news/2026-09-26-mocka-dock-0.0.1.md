Title: Mocka Dock 0.0.1 alpha
Date: 2026-09-26
Slug: mocka-dock-0-0-1
Summary: The first Mocka component is out for testing.

Mocka is a GTK desktop built for FreeBSD and GhostBSD first, replacing MATE
one component at a time. Every component is written from scratch,
compatible with MATE, and released under the BSD-3-Clause license.

Mocka Dock is the first of them, a taskbar-style dock applet for the MATE
panel. This is an alpha meant for testing, so expect missing features and
rough edges.

## What works

Pinned and running apps share one row of buttons, one button per app, on
horizontal and vertical panels of any size. Left click launches, activates
or minimizes an app, and opens a list of windows when there is more than
one. Middle click, or Shift and click, opens a new instance.

Pin an app from its right click menu, or by dragging it from the menu, the
desktop or the file manager, and reorder by dragging. Unpinning offers an
Undo. Several docks share the same pinned apps.

Right click an app for its desktop actions, its recent files, a new
instance, Pin or Unpin, and Close. Shift and right click opens the standard
window menu, Ctrl and right click the dock's own menu.

Apps are recognized by their desktop entry, including web apps from
Chromium-based browsers. By default the dock shows windows from the current
workspace only.

## Not in this release

Window thumbnails on hover are the next milestone, and a list of window
titles stands in for them meanwhile. Super and number shortcuts, mouse
wheel window cycling, attention blinking and translations are not there
yet.

There is no Preferences window, so settings are changed with `gsettings`
for now. The release notes give the commands.

Three limitations are worth knowing about. LibreOffice windows cannot be
pinned from their right click menu, because LibreOffice does not name its
windows after its modules on FreeBSD, so drag Writer or Calc from the menu
instead. Recent files come from the system list, so apps that keep their
own history show none. The dock runs inside mate-panel, which means a crash
in the dock restarts the panel.

## Getting it

Mocka Dock arrives in the next GhostBSD package update. It will be
preinstalled, but it is not the default yet, so add it yourself: right
click the panel, choose Add to Panel, and pick Mocka Dock.

It needs FreeBSD or GhostBSD with X11, MATE panel 1.26 or later, GTK
3.24.20 or later, and libwnck 40 or later.

## Reporting bugs

Please [open an issue](https://github.com/mocka-desktop/mocka-dock/issues)
with what you did, what you expected, and what happened. If an app lands on
the wrong button, the release notes explain how to collect the data that
makes it fixable.

The [full release
notes](https://github.com/mocka-desktop/mocka-dock/releases/tag/0.0.1) have
the complete list and the build instructions.
