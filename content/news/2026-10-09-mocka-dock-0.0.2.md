Title: Mocka Dock 0.0.2 alpha
Date: 2026-10-09
Slug: mocka-dock-0-0-2
Summary: Window thumbnails arrive in the second Mocka Dock alpha.

Mocka Dock 0.0.2 is the second alpha for GhostBSD testers. The big addition
is window thumbnails.

## What's new

Hover a running app's button to see a thumbnail of each of its windows.
Click a thumbnail to bring that window forward, or to minimize the one you
are using, and hover it to show its close button. Clicking an app with
several windows now shows its thumbnails straight away, replacing the plain
window list from 0.0.1. Apps with many windows wrap their thumbnails onto
more rows, so every window stays on screen.

With a compositor running, thumbnails show what is in each window, even
windows covered by others, and they update live while the popup is open.
Marco's compositor is enough: Control Center, Windows, General, "Enable
software compositing window manager". Nothing is captured while the popup
is closed, so the dock stays idle. Minimized windows show how they looked
when they last lost focus. Without a compositor, each thumbnail shows the
window's icon and title, and clicking and closing still work.

Bug reports are easier too: `mocka-dock-collect-test-data` is now installed
with the dock, so you no longer need the source tree to send the data for
an app that lands on the wrong button.

This release also fixes a crash risk when the panel shuts down with an app
that has no desktop entry.

## A question for testers

Clicking an app with several windows shows its thumbnails, and clicking
again hides them, even when hovering already showed them. On Windows 11, a
click keeps them open instead. Which do you prefer? Tell us in the [forum
thread](https://github.com/orgs/mocka-desktop/discussions/1) or in an
[issue](https://github.com/mocka-desktop/mocka-dock/issues).

## Still to come

Super and number shortcuts, mouse wheel window cycling, attention blinking,
the Preferences window, the trash and translations.

## Known limitations

LibreOffice windows cannot be pinned from their right click menu, so drag
Writer or Calc from the menu instead. Recent files come from the system
list, so apps that keep their own history show none. Turning the compositor
on or off while the thumbnail popup is open takes effect on the next hover.
The dock runs inside mate-panel, so a crash in the dock restarts the panel.

## Getting it

Mocka Dock 0.0.2 arrives with the next GhostBSD package update. Upgrade
with `pkg upgrade`, or install it with `pkg install mocka-dock` if you do
not have it yet. If the dock is already on a panel, restart the panel to
load the new version: `mate-panel --replace &`. To add it for the first
time, right click the panel, choose Add to Panel, and pick Mocka Dock.

The [user guide](https://github.com/mocka-desktop/mocka-dock/wiki) covers
everything the dock does. The [release
notes](https://github.com/mocka-desktop/mocka-dock/releases/tag/0.0.2) list
every change, and the
[README](https://github.com/mocka-desktop/mocka-dock#readme) has the build
instructions.
