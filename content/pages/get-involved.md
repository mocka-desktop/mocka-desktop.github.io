Title: Get Involved
Slug: get-involved
Summary: How to help with Mocka, whether through code, testing, design or translation.

Mocka is developed in the open on GitHub. Work happens in the repository of
the component it belongs to, and anything broader is discussed in
[Discussions][discussions].

## Code

Every component is its own repository in the [GitHub organization][org].
Pull requests are welcome. For anything larger than a fix, raise it in
[Discussions][discussions] first, so the approach is agreed before you
spend time on it.

## Testing

Testing is the most useful thing you can do right now. Install the alpha on
GhostBSD and use it the way you normally work.

Report what breaks as an issue in that component's repository. Include the
steps you took, what you expected, and what happened instead. A small,
repeatable case is worth more than a long description.

## Design

Mockups, icons and interface ideas are welcome in [Discussions][discussions].
Mocka follows how the MATE tools behave, so suggestions that change familiar
behaviour are worth explaining rather than only showing.

## Translation

Translations are not set up yet. Watch [Discussions][discussions] for the
announcement when they are, and please do not start translating before
then, so no work is wasted.
